# Alloy Aviation

A premium private aviation landing page for Alloy Aviation, built as a responsive single-page website.

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Files

- `index.html` — page structure and content
- `styles.css` — branding, layout, responsive styling
- `script.js` — mobile menu and form interaction
